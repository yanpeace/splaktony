# Splak Tony

Gioco mobile antistress in pixel art: colpisci Tony, il pupazzo di pezza, guadagna monete, compra armi migliori.

```
npm install
npm run dev -- --host
```

Dal telefono (stessa Wi-Fi) apri l'indirizzo `Network:` stampato da Vite, es. `http://192.168.1.x:5173`.

Prima di modificare il codice leggi [ARCHITECTURE.md](ARCHITECTURE.md).
