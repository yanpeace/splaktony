# Splak Tony

Gioco mobile antistress in pixel art: colpisci Tony, l'operaio del cantiere della galleria, guadagna monete, compra armi migliori.

**Gioca online:** https://yanpeace.github.io/splaktony/ (si installa come app: Android "Installa app", iPhone Condividi → "Aggiungi alla schermata Home").
Ogni push su `main` ripubblica il gioco in automatico (GitHub Actions → Pages).

```
npm install
npm run dev -- --host
```

Dal telefono (stessa Wi-Fi) apri l'indirizzo `Network:` stampato da Vite, es. `http://192.168.1.x:5173`.

Prima di modificare il codice leggi [ARCHITECTURE.md](ARCHITECTURE.md).
